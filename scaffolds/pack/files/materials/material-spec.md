# 材质规范（{{domain}}）

> 本文件是**行业知识**，不是参考资料。它规定了"什么样算对"，Agent 与评测维度都以此为准。
> 写规范的原则：**每条都要能被机器判**。判不了的就别写进来（那是审美，交给 `accept` 的人决定）。

## 木作

| 项 | 规范 | 判据 |
| --- | --- | --- |
| 色温 | 3800–4500K（北欧风：偏冷白） | 渲染图灰世界白平衡估计 |
| 纹理尺度 | 大板 1.8–2.2m 内可见 1–2 处年轮节点 | 纹理重复检测 |
| 粗糙度 | 0.45–0.60（哑光，不许反光塑料感） | 材质参数区间 |
| 方向一致性 | 同房间地板纹理方向必须一致 | 纹理方向向量比对 |

## 织物（沙发 / 地毯 / 窗帘）

| 项 | 规范 | 判据 |
| --- | --- | --- |
| 粗糙度 | ≥ 0.75 | 材质参数区间 |
| 同一材质复用上限 | 家具中同一材质最多出现 40% | `material.repeat` |
| 窗帘透光率 | 0.25–0.45（要能看见窗外轮廓） | 窗户区域像素对比 |
| 起球/毛发 | 不允许（渲染伪影最常见来源） | 高频噪声检测 |

## 玻璃

| 项 | 规范 | 判据 |
| --- | --- | --- |
| 折射率 | 1.50±0.02 | 材质参数 |
| 厚度感 | 必须有，不能是单面片 | 网格水密性 / 双面检测 |
| 反射率 | ≤ 0.08（家居玻璃不该像镜子） | 材质参数 |

## 光照（这条最常被 Agent 搞坏）

| 项 | 规范 | 判据 |
| --- | --- | --- |
| 日光强度 | 0.9–1.1（基准 1.0） | `lighting.exposure` |
| 过曝像素比 | < 3% | 亮度 > 0.95 的像素占比 |
| 窗户遮挡 | 窗前 1.5m 内不得有高过窗台（0.9m）的家具 | `lighting.window` |
| 环境光 | 0.5–0.8（低于 0.3 会出现死黑） | 材质参数 |

---

## 怎么用这份规范

1. **做维度**：能被机器判的（上表「判据」列）→ 实现为 `evaluators`（见 `harness-plugin` 模板）。
2. **做批判**：Agent 每次 `edit` 后，把违反的条目写进 `reason`/`expect`，归因表才读得懂。
3. **做验收**：`benchmark/cases.json` 里的每个 case 都要能对上本文件的某一条。

> 校验方式：拿 `scenes/living-room.json` 跑一次 `evaluate`，把每个违规项在本文中找到对应行。
> 出现「本文没写、评测却扣分」或「本文写了、评测算不出来」的情况，都是规范或实现有 bug。
