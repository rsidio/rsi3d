# \{{project}}

由模板 `{{project}}` 生成（\{{date}}）。

这里就是**产物的内容**：把你要交付给使用者的文件放在本目录下（可以建子目录）。
文件名与内容里都可以用占位符，例如这个文件名叫 README.md，而你正在看的是其中一节。

## 占位符

- `\{{project}}` —— 使用者用 `--var project=…` 提供的值
- `\{{note}}` —— 见 `scaffold.json` 的 vars 声明
- 内置变量：`\{{date}}`（生成日期）、`\{{template}}`（模板 id）、`\{{engine_version}}`

> 本文件里的反斜杠是**刻意的**：它让占位符活到下一层渲染（详见本模板根目录的 README）。
> 如果你在这里写 `\{{project}}`（不带反斜杠），它会在你现在看到之前就被替换成模板名了。
